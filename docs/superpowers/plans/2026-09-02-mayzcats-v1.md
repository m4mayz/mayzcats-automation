# MayzCats V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a Colab-ready MayzCats pipeline that researches, renders, and privately uploads one recoverable YouTube Short per run.

**Architecture:** The wrapper owns product logic and calls the unmodified MoneyPrinterTurbo CLI only for base composition. External APIs and filesystem effects sit behind focused clients; persistent state is written atomically to Drive and topic history is committed only after upload success.

**Tech Stack:** Python 3.11+, httpx, PyYAML, python-dotenv, sentence-transformers, FFmpeg/ffprobe, ASS subtitles, MoneyPrinterTurbo CLI, Google YouTube Data API v3.

**Spec:** `docs/superpowers/specs/2026-09-02-mayzcats-v1-design.md`

## Global Constraints

- Never edit `sources/` and never make a public or unlisted YouTube upload.
- Voice ID is `cgSgspJ2msm6clMCkdW9`; model is `eleven_multilingual_v2`; speed is `1.08`.
- Valid narration duration is inclusive 35-55 seconds.
- Final video is exactly 1080x1920 at 30 fps with Montserrat Bold overlays.
- Successful uploads remove local run artifacts; failed uploads retain a complete Drive package.
- This workspace is not a Git repository, so commit steps are not applicable.
